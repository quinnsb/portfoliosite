A web application that generates an infinitely scrolling page of procedurally generated content. The content is meaningless but grammatically correct, creating the sensation of reading without the burden of comprehension.

## 2026.04.05

Deployed to production. The scroll has been scrolling for approximately 72 hours without incident. No one has reached the bottom, because there is no bottom.

## 2026.02.20

Implemented the Markov chain text generator. Current output reads like a corporate earnings call transcript written by someone experiencing mild dissociation. This is intentional.

## 2026.01.15

Project initiated. The premise: what if a webpage simply never ended? Not in the "lazy loading more content" sense, but in the existential sense. The scroll bar becomes a progress indicator for nothing.
